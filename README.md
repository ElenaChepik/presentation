# Оценка качества результатов применения ИИ. Проверка источников и выбор ИИ-инструмента.

Готовая страница для GitHub Pages. Сборка и установка зависимостей не нужны.

## Состав

- `index.html` — вся страница со встроенными изображениями, стилями, интерактивами и файлами для скачивания.
- `.nojekyll` — публикация готового HTML без обработки Jekyll.
- `.gitattributes` — настройки текстовых файлов.
- `README.md` — эта инструкция.

Для локального просмотра откройте `index.html` в браузере. Изображения, копирование запросов, чек-лист и таблица наблюдений работают без внешних библиотек. Ссылки на сервисы открывают их сайты. Отметки и наблюдения сохраняются в браузере посетителя и не отправляются в репозиторий.

## Публикация через интерфейс GitHub

1. Создайте репозиторий или откройте подготовленный для этой лекции. Для GitHub Free используйте публичный репозиторий.
2. Распакуйте архив и загрузите **содержимое папки** в корень репозитория: Add file → Upload files. `index.html` должен находиться в корне, а не внутри дополнительной папки. Загружать сам ZIP вместо файлов не нужно.
3. Сохраните файлы коммитом в ветку `main`.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Source → Deploy from a branch.
6. Укажите ветку `main` и папку `/(root)`, затем нажмите Save.
7. Дождитесь завершения публикации и откройте адрес через Visit site в Settings → Pages.

Обычный адрес проекта: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Точный адрес покажет GitHub.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Обновление страницы

Замените `index.html` новой версией в той же ветке. После коммита дождитесь повторной публикации и обновите страницу в браузере.
